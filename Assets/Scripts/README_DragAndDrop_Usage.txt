# Система перетаскивания и использования предметов

## Обзор
Добавлена функциональность для работы с предметами во время перетаскивания в инвентаре.

## Новые возможности

### 1. Блокировка подбора во время перетаскивания
- Во время перетаскивания предмета в инвентаре нельзя подобрать новые предметы нажатием E
- Это предотвращает случайное подбирание предметов при перетаскивании

### 2. Использование предметов во время перетаскивания
- Во время перетаскивания можно использовать расходуемые предметы нажатием E
- Применяются эффекты предмета (лечение, увеличение характеристик)
- Расходуемые предметы удаляются из инвентаря после использования

## Как это работает

### Обычное состояние (без перетаскивания)
- **E** - подобрать предмет в инвентарь
- **ЛКМ** - использовать предмет из хотбара

### Во время перетаскивания
- **E** - использовать перетаскиваемый предмет (если он расходуемый)
- Подбор новых предметов заблокирован
- Визуальная подсказка показывает возможность использования

## Типы предметов

### Автоматическое определение типа по названию:
- **Лечение**: содержит "health", "heal", "лечение", "аптечка", "зелье", "potion"
- **Макс. здоровье**: содержит "maxhealth", "здоровье", "сердце", "heart", "vitality"
- **Макс. стамина**: содержит "stamina", "стамина", "энергия", "energy", "endurance"
- **Обычные**: все остальные предметы

## Технические детали

### Новые методы в InventorySystem:
- `SetDraggingState(bool)` - устанавливает состояние перетаскивания
- `IsDragging()` - проверяет, идет ли перетаскивание
- `TryUseDraggedItem()` - использует перетаскиваемый предмет

### Обновления в InventoryDragDrop:
- Уведомляет InventorySystem о начале/конце перетаскивания
- Интеграция с системой состояний

### Обновления в PickupableItem:
- Динамические подсказки в зависимости от состояния перетаскивания
- Интеграция с системой определения типов предметов

## Примеры использования

1. **Перетаскивание зелья лечения**:
   - Начинаем перетаскивать зелье
   - Нажимаем E - зелье используется, здоровье восстанавливается
   - Зелье удаляется из инвентаря

2. **Перетаскивание обычного предмета**:
   - Начинаем перетаскивать меч
   - Нажимаем E - ничего не происходит (меч не расходуемый)
   - Подсказка показывает, что подбор заблокирован

3. **Перетаскивание предмета увеличения характеристик**:
   - Начинаем перетаскивать "Сердце дракона"
   - Нажимаем E - максимальное здоровье увеличивается
   - Предмет удаляется из инвентаря
