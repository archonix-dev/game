# Промпт для Suno V5 - Главное меню

## Описание игры
Игра про группу старых компьютеров (1990 года производства) под организацией Firewall Inc., которые борются с мутировавшими компьютерными вирусами. В главном меню изображены мониторы (интерфейс с помощью world space), а на заднем фоне - множество разрушенных мониторов (компьютеров), которые вирус разрушил.

## Рекомендации по использованию

### Настройки в Suno V5:
- **Стиль**: Instrumental (без вокала)
- **Жанр**: Synthwave / Cyberpunk / Ambient Electronic
- **Темп**: 70-90 BPM (медленный-средний)
- **Настроение**: Melancholic, Nostalgic, Atmospheric, Dark
- **Эпоха**: 1990s / Retro-futuristic

### Дополнительные теги для улучшения результата:
- `vintage computer game music`
- `retro synthwave`
- `cyberpunk ambient`
- `post-apocalyptic technology`
- `nostalgic 90s computer`
- `broken technology aesthetic`
- `quarantine zone atmosphere`
- `Firewall Inc. theme`

### Ожидаемый результат:
Музыка должна создавать атмосферу ностальгии по старым компьютерам 1990-х, с легкой меланхолией и мрачностью, но не слишком агрессивная. Должна подходить для главного меню - быть атмосферной, но не отвлекающей. Элементы ретро-синтезаторов, эмбиентные текстуры, возможно легкие глитч-эффекты, напоминающие о сломанных компьютерах.

## Примеры вдохновения
- Blade Runner (1982) - атмосферная электронная музыка
- Tron (1982) - ретро-футуристический саундтрек
- Система разрушения (1990s computer games) - ностальгическая музыка игр
- Synthwave композиции 2010s - современная интерпретация ретро-эстетики
