# Инструкция по настройке мультиплеера после исправлений

## Важные изменения

Код был исправлен для правильной синхронизации игроков в лобби между всеми клиентами. Теперь `PlayerLobbyItem` является `NetworkBehaviour` и синхронизируется через Unity Netcode.

## Что нужно сделать в Unity Editor

### 1. Настройка префаба `playerLobbyPrefab`

**КРИТИЧЕСКИ ВАЖНО:** Префаб `playerLobbyPrefab` должен иметь компонент `NetworkObject`:

1. Откройте префаб `playerLobbyPrefab` в инспекторе
2. Убедитесь, что на префабе есть компонент `NetworkObject`
3. Если компонента нет, добавьте его:
   - Нажмите "Add Component"
   - Найдите и добавьте "Network Object"
4. В компоненте `NetworkObject`:
   - `Always Replicate As Root`: можно оставить выключенным
   - `Synchronize Transform`: можно выключить (для UI не нужно)
   - Остальные настройки по умолчанию

### 2. Регистрация префаба в NetworkPrefabsList

Префаб `playerLobbyPrefab` должен быть зарегистрирован в `NetworkPrefabsList`:

1. Найдите объект `DefaultNetworkPrefabs` (или создайте новый `NetworkPrefabsList`)
2. В инспекторе `NetworkPrefabsList`:
   - Убедитесь, что `playerLobbyPrefab` добавлен в список префабов
   - Если его нет, добавьте через кнопку "+"
   - Перетащите префаб `playerLobbyPrefab` в список

3. В `NetworkManager`:
   - Убедитесь, что `NetworkPrefabsLists` содержит ссылку на ваш `NetworkPrefabsList`
   - Если нет, добавьте через кнопку "+" и перетащите `NetworkPrefabsList`

### 3. Проверка компонентов на префабе

Убедитесь, что на префабе `playerLobbyPrefab` есть:
- ✅ `NetworkObject` компонент
- ✅ `PlayerLobbyItem` компонент (скрипт)
- ✅ Все UI элементы назначены в инспекторе

### 4. Настройка NetworkManager

В `NetworkManager` проверьте:
- `Network Transport` должен быть `Unity Transport`
- `NetworkPrefabsLists` должен содержать ваш список префабов
- `Default Player Prefab` можно оставить пустым (для лобби не нужен)

## Как это работает теперь

1. **Создание лобби (хост):**
   - При создании лобби хост создает `PlayerLobbyItem` через `NetworkObject.Spawn()`
   - Это автоматически синхронизирует объект со всеми клиентами

2. **Подключение клиента:**
   - Клиент подключается к лобби
   - Сервер создает `PlayerLobbyItem` для нового клиента
   - Объект автоматически синхронизируется с клиентом через Unity Netcode

3. **Синхронизация данных:**
   - Имя игрока синхронизируется через `NetworkVariable<FixedString64Bytes>`
   - Цвет игрока синхронизируется через `NetworkVariable<Color>`
   - Статус админа синхронизируется через `NetworkVariable<bool>`
   - ClientId синхронизируется через `NetworkVariable<ulong>`

4. **Выбор цвета:**
   - Клиент выбирает цвет через `ColorSelectionPanel`
   - Цвет отправляется на сервер через `ServerRpc`
   - Сервер обновляет `NetworkVariable`, что автоматически синхронизирует цвет со всеми клиентами

## Возможные проблемы и решения

### Проблема: Игроки не видят друг друга в лобби

**Решение:**
1. Убедитесь, что префаб `playerLobbyPrefab` имеет компонент `NetworkObject`
2. Убедитесь, что префаб зарегистрирован в `NetworkPrefabsList`
3. Проверьте логи Unity - должны быть сообщения о синхронизации

### Проблема: Цвет игрока не синхронизируется

**Решение:**
1. Убедитесь, что `PlayerLobbyItem` наследуется от `NetworkBehaviour` (уже исправлено в коде)
2. Проверьте, что `NetworkVariable<Color>` правильно инициализирован
3. Проверьте логи - должны быть сообщения о вызове `ServerRpc`

### Проблема: Ошибка "NetworkObject not found"

**Решение:**
1. Добавьте компонент `NetworkObject` на префаб `playerLobbyPrefab`
2. Убедитесь, что префаб зарегистрирован в `NetworkPrefabsList`

## Тестирование

1. Запустите игру в двух экземплярах Unity (или на двух компьютерах)
2. В первом экземпляре создайте лобби (нажмите кнопку создания лобби)
3. Во втором экземпляре подключитесь к IP первого экземпляра
4. Оба игрока должны видеть друг друга в списке игроков
5. Выберите цвет в одном экземпляре - он должен синхронизироваться во втором

## Дополнительные заметки

- Все `PlayerLobbyItem` создаются только на сервере
- Клиенты получают их автоматически через синхронизацию Unity Netcode
- Данные синхронизируются в реальном времени через `NetworkVariable`
- При отключении игрока его `PlayerLobbyItem` автоматически удаляется у всех клиентов
