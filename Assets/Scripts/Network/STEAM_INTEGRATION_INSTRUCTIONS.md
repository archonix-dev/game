# Инструкции по интеграции Steam мультиплеера

## Обзор изменений

Проект был обновлен для использования Steam для мультиплеера. Вместо ввода IP адреса, игроки теперь используют Steam оверлей для приглашения друзей и подключения к лобби.

## Основные изменения

1. **SteamManager.cs** - Менеджер для инициализации Steam API
2. **SteamInitializer.cs** - Автоматически создает и инициализирует SteamManager при старте игры
3. **SteamLobbyManager.cs** - Менеджер для управления Steam лобби
4. **ConnectToLobbyPanel.cs** - Обновлен для открытия Steam оверлея вместо ввода IP
5. **LobbyManager.cs** - Обновлен для создания Steam лобби при создании игры

## Автоматическая инициализация Steam

**ВАЖНО:** Для автоматической инициализации Steam при старте игры используйте компонент `SteamInitializer`:

1. Добавьте `SteamInitializer` на GameObject в первой сцене (обычно Menu)
2. Компонент автоматически создаст `SteamManager`, если его нет
3. Steam будет инициализирован при старте игры

Если Steam не инициализируется:
- Убедитесь, что Steam клиент запущен
- Убедитесь, что вы вошли в аккаунт Steam
- Проверьте, что файл `steam_appid.txt` существует в корне проекта (создается автоматически)
- Проверьте логи Unity на наличие ошибок

## Установка Steamworks.NET

### Шаг 1: Установка Steamworks.NET

⚠️ **ВАЖНО:** Используйте ТОЛЬКО Unity Package Manager для установки! Ручная установка может вызвать ошибки компиляции.

**Установка через Unity Package Manager (РЕКОМЕНДУЕТСЯ):**

1. Откройте Unity
2. Window → Package Manager
3. Нажмите "+" → Add package from git URL
4. Введите: `https://github.com/rlabrecque/Steamworks.NET.git?path=/com.rlabrecque.steamworks.net`
5. Дождитесь установки
6. Проверьте, что нет ошибок компиляции

**Если возникли ошибки компиляции CS1028:**

1. Удалите любые вручную установленные версии Steamworks.NET:
   - Удалите папку `Assets/Steamworks.NET-master` (если есть)
   - Удалите папку `Assets/Plugins/Steamworks.NET` (если есть)
2. Используйте только версию через Package Manager
3. См. `STEAM_FIX_COMPILATION_ERRORS.md` для подробных инструкций

**⚠️ НЕ используйте ручную установку!** Это может вызвать ошибки компиляции с директивами препроцессора.

### Шаг 2: Настройка Steam App ID

1. Создайте файл `steam_appid.txt` в корне проекта (рядом с `Assets/`)
2. Введите ваш Steam App ID (для тестирования можно использовать `480` - Spacewar)
3. Для продакшена получите свой App ID в Steamworks Partner Portal

**Пример steam_appid.txt:**
```
480
```

### Шаг 3: Настройка в Unity

**ВАЖНО:** Есть два способа настройки:

#### Способ 1: Автоматическая инициализация (рекомендуется)

1. Откройте первую сцену, которая загружается при старте игры (обычно "Menu" или "Bootstrap")
2. Создайте пустой GameObject и назовите его `SteamInitializer`
3. Добавьте компонент `SteamInitializer`
4. Настройте параметры:
   - `Steam App ID` - установите ваш App ID (или оставьте 480 для тестирования)
   - `Auto Initialize` - включите (по умолчанию включено)
   - `Auto Create Steam Manager` - включите (по умолчанию включено)
5. `SteamInitializer` автоматически создаст `SteamManager` при старте игры

#### Способ 2: Ручная настройка

1. Откройте сцену с меню
2. Создайте пустой GameObject и назовите его `SteamManager`
3. Добавьте компонент `SteamManager`
4. Установите `Steam App ID` в инспекторе (или оставьте 480 для тестирования)
5. Включите `Auto Initialize`

#### Создание SteamLobbyManager

6. Создайте еще один GameObject и назовите его `SteamLobbyManager`
7. Добавьте компонент `SteamLobbyManager`
8. Настройте параметры лобби:
   - `Max Lobby Members` - максимальное количество игроков (по умолчанию 8)
   - `Lobby Type` - тип лобби (FriendsOnly, Public, Private, Invisible)

### Шаг 4: Обновление UI

1. Откройте панель `ConnectToLobbyPanel` в Unity
2. Удалите старые поля ввода IP и пароля (если они есть)
3. Добавьте две кнопки:
   - `Invite Friend Button` - для приглашения друзей (для хоста)
   - `Join Friend Button` - для подключения к другу
4. Назначьте кнопки в инспекторе `ConnectToLobbyPanel`

## Использование

### Создание лобби (Хост)

1. Нажмите кнопку "Играть" в меню
2. Система автоматически создаст Steam лобби и Unity Netcode лобби
3. Для приглашения друзей нажмите кнопку "Подключиться к другому лобби"
4. Нажмите "Пригласить друга" - откроется Steam оверлей
5. Выберите друга из списка и отправьте приглашение

### Подключение к лобби (Клиент)

1. Нажмите кнопку "Подключиться к другому лобби"
2. Нажмите "Присоединиться к другу" - откроется Steam оверлей
3. Выберите друга из списка, который находится в лобби
4. Примите приглашение или выберите "Присоединиться к игре"
5. Система автоматически подключит вас к Unity Netcode лобби

## Важные замечания

### Для разработки и тестирования

- Используйте Steam App ID `480` (Spacewar) для тестирования без публикации в Steam
- Убедитесь, что Steam клиент запущен перед запуском игры
- Для тестирования локально используйте два разных Steam аккаунта

### Для продакшена

1. Получите свой Steam App ID в Steamworks Partner Portal
2. Обновите `steam_appid.txt` с вашим App ID
3. Обновите `SteamManager.steamAppId` в коде или через инспектор
4. Убедитесь, что игра правильно настроена в Steamworks

### Ограничения текущей реализации

⚠️ **Важно**: Текущая реализация использует Steam Lobby API для поиска и подключения, но для полноценной работы через Steam P2P нужен кастомный transport для Unity Netcode на основе SteamNetworkingSockets.

Сейчас система работает следующим образом:
- Steam Lobby используется для поиска и приглашения друзей
- Unity Netcode с UnityTransport используется для игрового соединения
- Для полноценной Steam интеграции рекомендуется создать SteamNetworkingSockets transport

## Решение проблем

### Steam не инициализируется

1. Убедитесь, что Steam клиент запущен
2. Проверьте, что файл `steam_appid.txt` существует и содержит правильный App ID
3. Проверьте логи Unity на наличие ошибок Steam API

### Не удается подключиться к лобби

1. Убедитесь, что оба игрока находятся в одной Steam сети
2. Проверьте, что хост создал лобби успешно
3. Убедитесь, что приглашение было отправлено и принято

### Ошибки компиляции

1. Убедитесь, что Steamworks.NET правильно установлен
2. Проверьте, что все DLL файлы находятся в правильных папках
3. Перезапустите Unity после установки Steamworks.NET
