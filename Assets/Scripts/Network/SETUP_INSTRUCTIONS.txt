✅ ШАГ 1: Добавление SteamLobbyManager в сцену Menu
──────────────────────────────────────────────────

1. Откройте сцену Menu (Assets/Menu.unity)
2. Создайте новый пустой GameObject:
   - Правый клик в Hierarchy → Create Empty
   - Назовите его "SteamLobbyManager"

3. Добавьте компонент SteamLobbyManager:
   - Выберите объект "SteamLobbyManager"
   - В Inspector нажмите "Add Component"
   - Найдите и добавьте "Steam Lobby Manager"

4. Настройте параметры в Inspector:
   - Lobby Type: FriendsOnly (рекомендуется)
   - Invite Key: I (или любая другая клавиша)

5. Сохраните сцену (Ctrl+S)

═══════════════════════════════════════════════════════════════════

✅ ШАГ 2: Использование системы приглашений
──────────────────────────────────────────────────

Теперь система готова к использованию!

ДЛЯ ХОСТА (создавшего лобби):
• Создайте лобби через обычный интерфейс
• Нажмите клавишу "I" на клавиатуре
• Откроется Steam оверлей с друзьями
• Выберите друзей для приглашения

ДЛЯ ГОСТЯ (получившего приглашение):
• Получите уведомление в Steam
• Нажмите "Принять" в уведомлении
• Игра автоматически подключится к лобби

✅ ШАГ 3: Проверка работоспособности
──────────────────────────────────────────────────

1. Запустите игру
2. Убедитесь, что Steam запущен
3. Создайте лобби
4. Нажмите "I" - должен открыться Steam оверлей
5. Проверьте консоль Unity на логи:
   [SteamLobbyManager] Steam callbacks инициализированы
   [SteamLobbyManager] Открытие диалога приглашения...

📌 ВАЖНЫЕ ЗАМЕЧАНИЯ
──────────────────────────────────────────────────

• Steam ДОЛЖЕН быть запущен на компьютере
• У игроков должна быть установлена игра
• Приглашения работают только между друзьями Steam
• SteamLobbyManager автоматически создаётся как Singleton
• Компонент помечен как DontDestroyOnLoad

🐛 УСТРАНЕНИЕ ПРОБЛЕМ
──────────────────────────────────────────────────

ПРОБЛЕМА: Оверлей не открывается
РЕШЕНИЕ:
  • Проверьте, что Steam запущен
  • Убедитесь, что лобби создано
  • Включите Steam оверлей в настройках Steam:
    Steam → Settings → In-Game → Enable Steam Overlay

ПРОБЛЕМА: Друзья не получают приглашения
РЕШЕНИЕ:
  • Проверьте тип лобби (должен быть FriendsOnly или Public)
  • Убедитесь, что они в вашем списке друзей
  • Проверьте, что у них установлена игра

ПРОБЛЕМА: Ошибка "SteamLobbyManager.Instance == null"
РЕШЕНИЕ:
  • Убедитесь, что GameObject с SteamLobbyManager создан в сцене
  • Проверьте, что компонент правильно добавлен

💡 ДОПОЛНИТЕЛЬНЫЕ ВОЗМОЖНОСТИ
──────────────────────────────────────────────────

Вы можете добавить кнопку в UI для приглашений:

1. Создайте кнопку в UI
2. Добавьте на неё скрипт с методом:

   public void OnInviteButtonClicked()
   {
       if (SteamLobbyManager.Instance != null)
       {
           SteamLobbyManager.Instance.InviteFriendToLobby();
       }
   }

3. Привяжите метод к событию onClick кнопки
