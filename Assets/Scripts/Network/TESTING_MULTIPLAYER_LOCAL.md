# Инструкция по тестированию мультиплеера на одном устройстве

## Использование ParrelSync для тестирования

ParrelSync позволяет запускать несколько экземпляров Unity Editor одновременно для тестирования мультиплеера на одном компьютере.

### Настройка ParrelSync

1. **ParrelSync уже установлен в проекте** (находится в `../ParrelSync-master/`)

2. **Создание клона проекта:**
   - В Unity Editor откройте меню: `ParrelSync` → `Clones Manager`
   - Нажмите кнопку `Create New Clone`
   - Выберите имя для клона (например, "Clone1")
   - ParrelSync создаст копию проекта в отдельной папке

3. **Запуск клона:**
   - В окне `Clones Manager` нажмите `Open in New Editor` для созданного клона
   - Откроется новый экземпляр Unity Editor с копией проекта

### Тестирование мультиплеера

#### Вариант 1: Тестирование через два экземпляра Unity Editor

1. **Запустите первый экземпляр (Хост):**
   - Откройте проект в первом Unity Editor
   - Запустите игру (Play)
   - Нажмите кнопку "Играть" для создания лобби
   - Откройте "Настройки лобби"
   - Скопируйте IP адрес, нажав кнопку "Копировать IP"

2. **Запустите второй экземпляр (Клиент):**
   - Откройте клон проекта во втором Unity Editor (через ParrelSync)
   - Запустите игру (Play)
   - Нажмите кнопку "Подключиться к другому лобби"
   - Вставьте скопированный IP адрес
   - Введите пароль лобби (если установлен)
   - Нажмите "Войти"

3. **Проверка подключения:**
   - Оба игрока должны видеть друг друга в списке игроков
   - Можно протестировать выбор цвета, синхронизацию и другие функции

#### Вариант 2: Тестирование через Build

1. **Создайте Build игры:**
   - File → Build Settings
   - Выберите платформу (Windows, Mac, Linux)
   - Нажмите "Build"

2. **Запустите хост в Unity Editor:**
   - Запустите игру в Unity Editor
   - Создайте лобби
   - Скопируйте IP адрес

3. **Запустите клиент из Build:**
   - Запустите собранную игру
   - Подключитесь к IP адресу хоста

### Важные замечания

1. **IP адрес для локального тестирования:**
   - При тестировании на одном компьютере используйте `127.0.0.1` или `localhost`
   - Для тестирования между разными устройствами используйте реальный IP адрес в локальной сети

2. **Порт:**
   - По умолчанию используется порт `7777`
   - Убедитесь, что порт не занят другим приложением
   - Если порт занят, измените его в настройках

3. **Брандмауэр:**
   - При тестировании на одном устройстве брандмауэр обычно не мешает
   - При тестировании между устройствами может потребоваться разрешить доступ через брандмауэр

4. **Копирование IP адреса:**
   - IP адрес можно скопировать через кнопку в панели "Настройки лобби"
   - Или вручную скопировать из текстового поля

### Решение проблем

**Проблема: Не удается подключиться**
- Убедитесь, что хост запущен и видит свой IP адрес
- Проверьте, что IP адрес введен правильно
- Проверьте, что порт совпадает на хосте и клиенте
- Убедитесь, что пароль введен правильно (если установлен)

**Проблема: ParrelSync не работает**
- Убедитесь, что ParrelSync установлен и активирован
- Попробуйте перезапустить Unity Editor
- Проверьте, что клон создан правильно

**Проблема: Порт занят**
- Измените порт в настройках NetworkManager
- Или закройте приложение, которое использует порт

### Альтернативные способы тестирования

Если ParrelSync не работает, можно использовать:

1. **Два Build'а:**
   - Соберите игру дважды в разные папки
   - Запустите оба экземпляра

2. **Unity Editor + Build:**
   - Один игрок в Unity Editor (хост)
   - Второй игрок из Build (клиент)

3. **Два компьютера в одной сети:**
   - Запустите хост на первом компьютере
   - Подключитесь с второго компьютера по IP адресу первого
