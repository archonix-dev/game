5. СХЕМА ПОТОКА АНИМАЦИЙ

        [idle]

      [grabstart] ──┐
           │        │

           │        │
           ▼        │
      [grabhold] ←──┘
           │        │
           │        │ Bool: grabhold = false
           │        │
           ▼        │
    [grabrelease] ──┘
           │
           │ Has Exit Time: 1.0 сек
           ▼
        [idle]


6. ПРОВЕРКА РАБОТЫ
   ────────────────
   
   ✓ Захватите предмет → должна проиграться grabstart
   ✓ Через 0.2 сек → должна начаться цикличная grabhold
   ✓ Удерживайте предмет → должна повторяться grabhold
   ✓ Отпустите предмет → должна проиграться grabrelease
   ✓ После завершения → должен вернуться idle

• Названия параметров должны точно совпадать:
  "grabstart", "grabhold", "grabrelease"
  
• Анимация grabhold ДОЛЖНА быть зациклена (Loop = ON)
  
• Анимации grabstart и grabrelease НЕ должны быть зациклены
  
• Exit Time для grabstart → grabhold должен быть 0.2 секунды
